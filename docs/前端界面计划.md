# TrustBridge 前端界面计划（Deal Explorer）

> 版本 v1.0（2026-10-31）。定位：给 TrustBridge 配一个**只读可视化前端**，让非工程师
> 看懂一笔 Agent 交易的生命周期。本文是 D1–D4 阶段计划；D1 交互 demo 已随本计划交付
> （对话内渲染 + 本文件同目录可导出）。

---

## 1. 为什么做（价值与评分映射）

| 受益 | 说明 |
|---|---|
| **B3 用户测试友好度** | 组外同学现在要读终端输出判断成功与否；图形化状态机 + 余额守恒面板把「跑通了没有」变成一眼可见 |
| **当天展示（评分 D）** | 8 分钟演示的分镜 S3–S5 可切到前端画面，比裸终端直观；委员会 L2 判级（4 inputs + 4 signers）可视化 |
| **Why-Lyquor 叙事** | 对照 EVM 版没有的事件溯源视图（证据根折叠、阈值签署轮），强化「委员会背书 + 存证」的差异化卖点 |

## 2. 已验证的技术事实（2026-10-31 实测）

1. **devnet JSON-RPC 开放 CORS**：`POST http://127.0.0.1:10087/api` 返回头
   `access-control-allow-origin: *`（eth_blockNumber 实测通）→ **浏览器可零后端直连节点**，
   不需要任何代理/服务器。
2. 只读查询面已具备：`deal_info(deal_id)` / `balance_of(agent)` / `due_deals()` /
   `evidence_entries(deal_id)` 均为 view（`agents/common/rpc.py` 已封装同型 eth_call）。
3. 实录数据齐全：T7 全绿 committee 流、R2 keeper 环、R1 正常流的逐字终端输出都在
   `workflow-out/_r*` 归档，可作回放数据源。

## 3. 架构

**单文件 HTML（零构建、零依赖），两种数据源：**

```
┌─ Deal Explorer（单 HTML）───────────────────────────────────┐
│  数据源 A：REPLAY（默认）—— 归档实录驱动，逐字 console +     │
│            状态机/余额/证据/委员会四面板步进动画              │
│  数据源 B：LIVE（D2）—— 直连 http://127.0.0.1:10087/api，    │
│            2s 轮询 deal_info/balance_of/evidence，只读        │
├──────────────────────────────────────────────────────────────┤
│  面板：① 状态机流水线（Qualified→Funded→Submitted→           │
│          Settled/Disputed→Refunded，高亮当前态与路径）        │
│        ② 余额三卡 + 资金守恒不变量（Σ ≡ 托管额 ✓）            │
│        ③ 委员会签署轮（4 节点 propose→aggregate→certified→    │
│          signers 映射，L2/L1/L0 判级徽章）                    │
│        ④ 证据日志（seq/kind/from→to + FNV-1a 根折叠说明）     │
│        ⑤ 终端镜像（实录行逐条流式高亮）                       │
└──────────────────────────────────────────────────────────────┘
```

**诚实纪律（继承项目红线）**：
- 前端是**展示层，不参与共识**——LIVE 模式只发 view 调用，绝不发交易、绝不重复 `e2_arm`/`run_round`；
- REPLAY 模式数据逐字取自归档实录并在界面上标注来源；不虚构哈希/余额/判级；
- LIVE 不可达时显式降级提示，不假装在线。

## 5. 风险

| 风险 | 缓解 |
|---|---|
| CORS 策略后续版本变化 | D2 启动时预检（同 today 的 curl 探测）；退化路径 = `scripts/serve_dashboard.py`（stdlib 单文件代理，加 CORS 头） |
| LIVE 轮询误读滞后块 | 沿用 demo 的读回重试口径（5×0.4s），面板标注「读路径可能滞后一块」 |
| 前端被误当信任面 | 页面固定显示「展示层 · 数据以链上读回为准 · 非共识组件」 |
